# Figure it out

Use this skill when the task needs a plan before implementation and no narrower skill owns the whole outcome.

1. Define the desired result as a predicate that can be checked on the real artifact.
2. Bound the scope, risks, dependencies, and irreversible decisions.
3. Break the work into independently verifiable units and start with the riskiest unknown.
4. For each unit, state the hypothesis, make the smallest change, and verify it before moving on.
5. Keep decisions and evidence in the task record when the work spans multiple phases.
6. Finish by checking the complete artifact against the original predicate and listing what remains unverified.

Prefer existing skills for architecture, verification, review, and documentation. Do not invoke host-specific tools or skills that are not in the active catalog.
