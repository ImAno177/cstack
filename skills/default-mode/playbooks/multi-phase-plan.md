### Multi-phase plan

The plan is the deliverable; execution starts only when requested.

1. Split work by dependency and owned artifact. Skip a plan for one or two obvious files.
2. Give each phase a done predicate, owner, file boundary, verification command, and handoff artifact.
3. Prototype unresolved product or architecture questions before freezing the plan.
4. Keep phases independently verifiable and delete obsolete intermediate paths at the boundary where they stop being needed.
