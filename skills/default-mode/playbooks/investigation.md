### Investigation

Own the answer. Investigation is read-only and produces an evidence-backed explanation or recommendation.

1. Route through `how`; add `why` when history or motivation matters.
2. Read the smallest source surface that can answer the question.
3. Produce overview, key concepts, mechanics, locations, gotchas, and a judgment. Use a tradeoff table for alternatives.
4. State what evidence would change the conclusion. Do not edit code or open a PR.
